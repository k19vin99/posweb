Aplicación Web Punto de Venta. Pensado para Almacenes de barrio, minimarket, botillería, etc.

Back End: Node.JS.
Base de Datos: PostgreSQL.
Front End: React.JS.

Funciones:

- Gestión de Inventario y Stock disponible de productos.
- Gestión de Empresas.
- Gestión de Almacenes o Almacen.
- Gestión de Usuarios.
- Getsión de Ventas.
- DashBoard.
- Perfil de Usuario.


Funciones Completas:
- Gestión de Empresas.
- Gestión de Almacenes o Almacen.

Funciones por Completar:
- Modulo de Ventas.
- DashBoard.
- Perfil de Usuario.






Comandos para arrancar sistema:

Arrancar Servidor Backend (Node.js):

cd backend
node index.js

Arrancar Servidor Frontend (React.js):

cd frontend
npm run dev
